# User Flow

This flow reflects the core idea of reducing the effort of deciding what to cook by turning available ingredients and personal preferences into practical meal suggestions.

## Primary Meal Discovery Flow

```text
Home / Welcome
   ↓
Choose What You Have
   ↓
Select Ingredients
   ↓
Set Preferences
   ├── Available Time
   ├── Mood
   └── Budget
   ↓
Get Meal Suggestions
   ↓
Browse / Compare Meals
   ↓
Select a Meal
   ↓
View Recipe Details
   ├── Ingredients
   ├── Cooking Time
   ├── Budget / Cost
   └── Cooking Instructions
   ↓
Start Cooking
   ↓
Complete Meal
```

# Flow Description

The user starts from the home screen and selects the ingredients they already have. They then provide additional preferences such as available cooking time, mood, and budget. Based on these inputs, Whatcha Got? presents relevant meal suggestions. The user can browse the suggestions, select a meal, view its recipe details, and follow the cooking instructions.
